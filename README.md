
# FORM Studio — Responsive Creative Agency Website

A modern, responsive fashion and creative agency website developed using HTML5, SCSS, CSS Flexbox, CSS Grid, and Vanilla JavaScript.

The project focuses on responsive web design, clean layouts, visual consistency, accessibility, and user experience.

## Live Demo

[View Live Website]([https://YOUR-USERNAME.github.io/YOUR-REPOSITORY/](https://samkitjn.github.io/Responsive/))

## About the Project

FORM Studio is a concept website for an independent creative agency specializing in fashion branding, creative direction, and digital design.

This project was developed to strengthen my frontend development skills and gain practical experience in building responsive, visually consistent, and maintainable website layouts.

## Features

- Fully responsive, mobile-first layout
- Responsive navigation with hamburger menu
- Modern dark-themed user interface
- CSS Flexbox and Grid-based layouts
- Reusable SCSS variables and mixins
- Fluid typography using CSS clamp()
- Responsive images and card components
- Interactive hover effects and smooth transitions
- Semantic HTML5 structure
- SEO-friendly metadata
- Keyboard-accessible navigation
- Reduced-motion support
- Lazy loading for improved image loading behavior

## Responsive Design

The website follows a mobile-first design approach with the following breakpoints:

| Device | Screen Width |
|--------|--------------|
| Mobile | Below 768px |
| Tablet | 768px and above |
| Laptop | 1024px and above |
| Desktop | 1240px and above |

CSS Grid, Flexbox, media queries, and fluid typography are used to create flexible layouts across different screen sizes.

## Getting Started

1. Clone the repository.

2. Open the project folder in Visual Studio Code.

3. Use Live Sass Compiler to compile style.scss into style.css.

4. Open index.html using Live Server.

No backend or database is required.
